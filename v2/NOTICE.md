Color Shades Native V2 contains:

- Color Shades by qeude, from Raycast extensions commit `6734d85992290066fd31a7f5bee3cca3d3545a1a`, `extensions/color-shades`, MIT. See `vendor/upstream-LICENSE`, the exact source in `fixtures/original/src`, and the original icon in `assets/color-shades.png`. Own V1 adaptation copyright almatkai 2026, MIT (`LICENSE-MIT`).
- Tezbar beta source fixtures at `fd300e276356587726566026f072563eb9c34cb1`, Apache-2.0 (`LICENSE-APACHE-2.0`). `fixtures/beta/sources.json` records exact paths and hashes. Tests compile the real `common.rs` and `v2_sdk.rs`; only Tauri's app/event symbols and the effect router are test doubles.
- color-namer 1.4.0, copyright Zeke Sikelianos 2016, MIT (`vendor/color-namer/LICENSE.md`). Complete NTC list and naming algorithm are retained. Runtime uses the same default Euclidean D65 Lab distance, not NTC's separate RGB/HSL approximation.
- Name that Color data by Chirag Mehta, CC-BY-2.5 (`LICENSE-CC-BY-2.5.txt`, original attribution in `vendor/ntc-upstream.js`; source <http://chir.ag/projects/ntc/>). `vendor/ntc.json` preserves all 1,566 names, values and order and adds generated camelCase export slugs. Those slugs were generated by change-case-all 1.0.15, not inferred by a substitute word-splitting algorithm.
- chroma-js 1.4.1 by Gregor Aisch, BSD-3-Clause (`vendor/chroma-js/LICENSE`). The Rust Lab computation ports this exact version's constants and operation order. Original implementation retained in `vendor/chroma-js/chroma.js`.
- color-convert 2.0.1 by Heather Arthur, MIT (`vendor/color-convert/LICENSE`). RGB/HSV/hex computations are ported from its original source (`conversions.js`) with JS Math.round semantics.
- change-case-all 1.0.15 and its camel-case/pascal-case/no-case dependencies, MIT; package metadata and licenses retained under `vendor/`. They are build-time data generation/oracle dependencies only.

Combined source package SPDX expression: `MIT AND Apache-2.0 AND BSD-3-Clause AND CC-BY-2.5`. Runtime Rust dependency licenses remain those of their respective crates; see Cargo.lock and crate notices when distributing a compiled host. No JavaScript, npm package, network lookup or V1 profile is used at runtime.
